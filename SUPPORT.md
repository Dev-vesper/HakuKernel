# Getting Support

HakuKernel is an experimental hobby operating system maintained through its
GitHub repository. Support is best-effort; response times are not guaranteed.

## Where to Ask

- For a reproducible bug or build failure, open a GitHub issue with a concise
  title and the steps needed to reproduce it.
- For a usage question or project discussion, use GitHub Discussions if it is
  enabled for the repository; otherwise open an issue labeled as a question.
- For a proposed feature, describe the use case and check
  [ROADMAP.md](ROADMAP.md) first.
- For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and do not
  post details publicly.

## Helpful Details to Include

- Your operating system and versions of Visual Studio/MSVC, NASM, Python, and
  QEMU.
- The exact command you ran and the complete relevant error output.
- For boot problems, the relevant portion of `build/serial.log` and whether
  the `HAKU-BOOT-OK` marker appears.
- The commit hash or branch you tested.
- The smallest steps or test image that reproduce the issue.

Do not attach passwords, private keys, personal data, or disk images
containing information you do not intend to publish. Redact sensitive data
before posting logs or screenshots.
